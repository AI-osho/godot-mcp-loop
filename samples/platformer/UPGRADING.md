# Minimal Platformer — delivery changes

Before this update, this game was used primarily as an integrated repository example. The development collection
now generates a self-contained project with its required input actions and no addon autoload/plugin wiring.
Included in 0.12.0; older 0.11.0 has a smaller catalog. Preserve the selected version's server/addon pair.

Unchanged: original gameplay scripts, scenes, images and their res://examples/platformer/ paths; existing regression
conditions and the default repository main scene. Added: project wrapper, license and player/design/upgrade guides.
The authoritative files remain in examples/platformer; generated copies are checked byte-for-byte.

Do not interpret packaging or documentation changes as a new level, balance pass, measured productivity improvement,
or human gameplay acceptance. Copy into a fresh folder; existing games and normal client registrations are not updated.
