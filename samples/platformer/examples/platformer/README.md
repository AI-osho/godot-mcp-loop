# Minimal Platformer

A small movement fixture for edit, input and position assertions; not a campaign with a title or ending.

## Distribution and play

This internal compatibility fixture is retained in 0.12.0; it is not in the six-game showcase. Earlier 0.11.0 has a smaller catalog.
The game itself does not need an AI account, network connection, Python or the MCP addon.

```sh
godot --headless --path . --import
godot --path .
```

Tested engine family: Godot 4.7 (4.7.2). The first import builds native resource/class caches.
For controls in Japanese see [PLAY.ja.md](PLAY.ja.md).

## Controls

Left/Right move; Space jumps. Close and relaunch to reset. There is no invented R/Enter restart shortcut.

## Use with an agent

Install the addon from the exact same selected server build, then open this project in the editor and configure
your client explicitly. Version labels alone do not prove source/registry equality; keep the actual selected server/addon distribution.
This game demonstrates game_input, game_wait_for, game_query and scenario_run.

Its main scene is `res://examples/platformer/main.tscn`. Paths stay identical to the integrated repository example.
The project includes 1 expected-success scenario(s). The platformer's intentional_failure.yaml is a
separate negative teaching example, not part of that success count.
Test scenes, fixed seeds and state-changing hooks prepare controlled conditions; they do not establish normal-input completion.

## Source and changes

The authoritative source remains `examples/platformer/` in the repository. This standalone delivery is generated by
scripts/sync-samples.mjs; edit the authority, then generate and check. Do not hand-edit the two game copies.
The game rules and original art are preserved. [UPGRADING.md](UPGRADING.md) explains the delivery changes;
[DESIGN.md](DESIGN.md) records the scope. Native startup, rendering, complete routes and human preference are separate gates.
